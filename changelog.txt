Changelog for metratec uhf-reader sdk for C

0.6.0
=====
Release Date: 06.03.2026

- Multiple API changes
  - mt_uhf_read_data() and mt_uhf_write_data() now take a timeout parameter
  - mt_uhf_get_identification() now returns error and takes a pointer to put data to
  - mt_uhf_errorcode_t replaced int as the usual error code
    -> this was done to have no conflicts over not standardized error values outside of POSIX
    -> This also increased the amount of error ids slightly but most cases have a one-to-one equivalent
  - mt_reader_heartbeat_set() renamed to mt_uhf_heartbeat_set()

- Multiple internal fixes to functions- Renamed a parameter in mt_uhf_init() to make it more clear (no code change)
- Added some internal state checking for safety
- Replaced #pragma use with include guard by #ifndef to fit ISO C
- Fixed string in QRG2_FCC
- Will now warn if trying to build under C++
- improvement of documentation
- Example code improvements

0.5.0
=====
Release Date: 05.12.2025

- QRG2 split into QRG2_FCC and QRG2_ETSI
- Scope set: SDK targets module devices
  - Pulsar_LR removed
  - DESKID_UHF_V2 (split to DESKID_UHF_V2_ETSI and DESKID_UHF_V2_FCC) set to unsupported
  - DwarfG2 and DwarfG2XR will be added in a future Release
- Init function mt_uhf_init() API changes 
  - now takes a reset done callback (can be NULL)
- Added function mt_uhf_timeout_set to set timeouts (for example for many tags)
- mt_uhf_read_data() API changed
  - Added mask
  - Added error count
  - clearified use of EPC buffer
- mt_uhf_write_data() API changed
  - Added mask
  - Added error count
  - clearified use of EPC buffer
  - moved data parameter
- mt_uhf_set_power() now allows length 0 to set all antennas
  - Fixed power set not working on devices without muxing (QRG2, DESKID)
- Macro MT_DEVICE_TYPE_SET now is defined as the device name from the header (for debugging purposes)
- PLRM is now set to support all regions
- Performance improvement in hex command generation (e.g. mt_uhf_set_inventory_mask()) with by use of new function mt_print_hex()
- Fixed issues with inventory buffering
- Fixed continious inventory buffer having last antenna during new round (instead it's now zero, unknown)
- Fixed continious inventory buffer found reset after round
- Fixed issue with continious inventory round end detection on devices without muxing
